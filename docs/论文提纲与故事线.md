# 论文提纲与故事线（供与师兄讨论）

## 核心一句话

> 图基向量检索（HNSW）在向量被量化压缩后，**图结构本身成为内存瓶颈**；我们首次把 RaBitQ 量化接入图搜索，并对图结构做重排序+delta 压缩，在保持 ~0.9 召回的前提下把索引总内存降低 **6.4×**。

## 统一指标（串起三块的"高大上"指标）

**"给定 Recall@10 下，每个向量的总索引内存（bytes/vector，= 向量码 + 图结构）"**。
- 这个指标天然由两部分组成：向量码（RaBitQ，32×）+ 图结构（重排+delta，~2×）。
- 用它画 memory–recall 曲线，本文方法在所有 recall 档位都最低。

## 故事线（动机链条，层层递进）

1. **背景**：HNSW 是图基 ANN 的 SOTA，但内存 = 原始向量（D×4B）+ 图结构（~M×4B/边），两者都很大。
2. **痛点/机会**：向量量化（RaBitQ，D bit）能把向量压 32×，但**压完之后图结构反成大头**（SIFT1M：向量 16MB vs 图 153MB，图占 90%）。
3. **贡献 1（把 RaBitQ 接进图搜索）**：RaBitQ 原文明确写"应用于图基方法是 future work"——我们完成这个集成（图搜索用 RaBitQ 无偏距离估计 + 精确重排）。
4. **贡献 2（压缩图结构）**：图结构用「重排序（RCM）+ delta 编码」压缩 ~1.7–2×，接近信息熵界。
5. **结果**：总内存 665→104MB（6.4×），召回 0.90（可调）。

## 章节结构

1. **Introduction**：背景（ANN/图检索）→ 动机（向量压缩后图成瓶颈）→ 贡献（三点）→ 结果预览。
2. **Preliminaries / Related Work**：
   - 图基 ANN：HNSW（分层可导航小世界图）。
   - 向量量化：PQ 及其变体、RaBitQ（无偏估计 + 理论误差界）。
   - 图重排序：Coleman et al.（缓存优化，非内存压缩）——**我们是首次把重排序用于图结构的内存压缩**。
3. **Method**：
   - 3.1 总览（两层压缩架构）。
   - 3.2 向量压缩集成：RaBitQ × 图搜索（无偏距离估计 + 精确重排）。
   - 3.3 图结构压缩：重排序（RCM/MLINA 目标）+ delta 编码（varint/bitpack）+ 信息熵分析。
4. **Experiments**：
   - 设置（SIFT1M/GIST1M，M=16）。
   - 主结果：B0–B3 的 memory–recall 表（总内存 6.4×）。
   - 消融：编码选型、重排序目标、RaBitQ rerank 规模。
   - 讨论：图压缩接近熵界 1.87×；可导航性来自分层而非 layer-0 diversification。
5. **Conclusion & Future Work**：增量更新、更强的压缩感知构建、C++ 高效实现（查询时间）。

## 需要和师兄确认的点

1. **主贡献定位**：是"RaBitQ 图集成 + 图压缩"（系统型），还是"图结构压缩"（方法型）？我倾向前者（因为图压缩单独只有 ~2×）。
2. **Recall 口径**：0.90（rerank=2000）vs 0.99（exact）的折中如何表述才站得住。
3. **题目方向**：如 "Memory-Efficient Graph-based ANN via Joint Vector and Graph Compression" 这类。
