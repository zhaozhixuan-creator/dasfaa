# 实验结果汇总

> 方法：邻近图（HNSW）索引的两层压缩——向量压缩（RaBitQ，完成其图基集成的 future work）+ 图结构压缩（重排序 + delta 编码，接近信息熵界）。

## 1. 实验设置

- 数据：SIFT1M（1M×128）、GIST1M（1M×960）。
- 图：faiss IndexHNSWFlat，M=16，efConstruction=200（M 扫描用 8/16/32）。
- 向量压缩：RaBitQ（D-bit 码，无偏距离估计），对照 PQ（16 字节码）。
- 图压缩：RCM 重排序 + delta 编码（Golomb-Rice，接近熵界）。
- 指标：总内存（向量+图）、图压缩率、Recall@10。
- 硬件：128 核 / 251GB RAM（单线程查询）。

## 2. 主结果（SIFT1M：B0–B3 内存与召回）

| 方法                                         | 向量  | 图结构         | 总内存         | Recall@10       |
| -------------------------------------------- | ----- | -------------- | -------------- | --------------- |
| B0 HNSW（原始）                              | 512MB | 153MB          | 665MB          | 0.991           |
| B1 HNSW + PQ(16B)                            | 16MB  | 153MB          | 169MB          | 0.997           |
| B2 HNSW + RaBitQ(16B)                        | 16MB  | 153MB          | 169MB          | 0.990           |
| **B3 本文（HNSW + RaBitQ + 图压缩）** | 16MB  | **82MB** | **98MB** | **0.990** |

- **总内存降低 6.8×**（665 → 98 MB）：向量 32× + 图 1.86×，**召回几乎无损（0.990 vs 0.991）**。
- **图压缩 1.86×**（153 → 82 MB，Golomb-Rice），逼近信息熵界 1.87×"。

## 3. 完成 RaBitQ 的 future work（图基集成）

RaBitQ 中提到"把量化应用于图基方法是 future work"

- 召回损失 100% 来自底层 beam 搜索（rabitq 下降 + exact beam = 1.000；exact 下降 + rabitq beam = 0.812），上层贪心下降无损。

| ef        | 256   | 512   | 1000  | 2000            |

## 4. 图压缩消融

### 4.1 编码选型（SIFT1M，RCM 重排后，信息熵界 1.87×）

| 编码                           | 压缩后           | 压缩率           |
| ------------------------------ | ---------------- | ---------------- |
| varint（LEB128）               | 98.9MB           | 1.55×           |
| bitpack b=18                   | 87.9MB           | 1.74×           |
| **Golomb-Rice k=15**     | **82.2MB** | **1.86×** |
| 信息熵下界（gap 熵 16.59 bit） | ~82MB            | 1.87×           |

### 4.2 重排序目标（SIFT 100k，varint）

| 重排序                         | 压缩率           |
| ------------------------------ | ---------------- |
| identity                       | 1.98×           |
| **RCM（带宽）**          | **2.04×** |
| degree-sort                    | 1.97×           |
| spectral（Fiedler/MLINA 松弛） | 1.97×           |
| Morton 空间填充                | 1.52×（1M）     |

- 结论：RCM 已最优；谱/度/Morton 均不优于 RCM。瓶颈是 ~25% 长程（diversification）边，1D 排序无法压缩。

### 4.3 参数 M 扫描（SIFT1M，Golomb-Rice）

| M  | 平均度 | 图原始  | 图压缩  | 压缩率 |
| -- | ------ | ------- | ------- | ------ |
| 8  | 22.1   | 88.3MB  | 50.1MB  | 1.76× |
| 16 | 38.3   | 153.1MB | 82.2MB  | 1.86× |
| 32 | 55.6   | 222.3MB | 116.4MB | 1.91× |

- 压缩率随 M 升高（邻居更聚集），说明压缩在不同图密度下均有效。

## 5. GIST1M 鲁棒性（960 维，M=32 适配高维）

| 指标                        | 值                                                                  |
| --------------------------- | ------------------------------------------------------------------- |
| 图压缩                      | 121.2MB → 65.5MB = **1.85×**（与 SIFT 的 1.86× 一致）      |
| 总内存 B0→B3               | 3960.5MB → 185.5MB = **21.4×**（960 维向量 32× 压缩放大）  |
| Recall@10（exact）          | 0.875（960 维 + 1M 规模下 HNSW 召回天花板偏低，数据属性非压缩所致） |
| Recall@10（RaBitQ ef=2000） | 0.811（与 exact 差距为 RaBitQ 距离误差，960 维可继续调大 ef）       |

- **图压缩率 SIFT 1.86× / GIST 1.85× 高度一致**，证明方法跨维度鲁棒、接近熵界。

## 6. 压缩感知构建（ 100k+Golomb-Rice 验证结果）

| 方法                | 平均度 | 压缩后 | 压缩率 | recall@10 |
| ------------------- | ------ | ------ | ------ | --------- |
| HNSW（diversified） | 35.4   | 7.1MB  | 1.99× | 0.998     |
| k-NN k=16 + 分层    | 31.5   | 6.3MB  | 1.99× | 0.907     |
| k-NN k=24 + 分层    | 39.5   | 7.9MB  | 1.99× | 0.953     |
| k-NN k=32 + 分层    | 47.5   | 9.5MB  | 1.99× | 0.972     |

- **验证结论**：减少 diversification（k-NN layer-0）图压缩**不能破 2×**——压缩率持平（1.99×），且召回随 k 下降（0.907~0.972 vs 0.998）。
- **深层结论**：HNSW 的 diversification 是"召回/边"的最优设计（35 度拿 0.998），去掉它用更多边（47 度）召回还更低。此前"精确 k-NN 图 2.58×"是孤立图假象。
- **图压缩天花板 = ~1.87×（信息熵界）**，Golomb-Rice 已摸到 1.86×。

## 7. 结论

1. **主贡献**：RaBitQ 图集成（补 future work，ef 补偿恢复召回 0.990）+ 图压缩（Golomb-Rice 1.86×，接近熵界）= 总内存 6.8×，召回几乎无损。
2. **图压缩**：1.86×（1M），RCM 重排 + Golomb-Rice 编码已到信息熵界。
3. **发现**：向量压缩后图成内存瓶颈；图压缩受 ~25% 长程边限制（熵界 1.87×）；RaBitQ 图集成需 ef 补偿。
